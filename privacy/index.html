سياسة الخصوصية — برق (Barq)

آخر تحديث: 2026-11-27 (الإصدار 4.1.3). «برق» أداة مستقلة لمساعدة المعلمين، وليست تابعة لوزارة التربية والتعليم.

العربية

الملخص: لا نبيع بياناتك ولا نعرض إعلانات ولا نتتبعك. الاتصال الوحيد بخادم يشغّله المطوّر هو للتحقق من رمز التفعيل وتنزيل حزم المكتبة. لا نرى بيانات نور ولا أسماء الطلاب ولا درجاتهم.

خادم التراخيص (رمز التفعيل)

  • الخادم: https://barq-license.barq-noor.workers.dev
  • ما يُرسل: عند «تفعيل»: رمز التفعيل الذي تكتبه فقط. بعد ذلك يُرسل رمز جلسة يُصدره الخادم (صلاحيته 3 أيام) عند تحديث الاشتراك وعند تنزيل حزمة دروس.
  • ما يعود: قائمة الحزم المتاحة لاشتراكك وملفات الدروس (بيانات JSON، دون أي كود قابل للتنفيذ).
  • ما يُحفظ على جهازك: رمز الجلسة وقائمة الحزم المسموحة وملفات الحزم التي نزّلتها، في تخزين الإضافة المحلي.
  • ما يحفظه الخادم لكل مشترك: الاسم أو التسمية التي يكتبها المسؤول، ورقم واتساب اختياريًا (يُستخدم فقط لإرسال الرمز إليك)، ورمز التفعيل (نسخة مُشفّرة للبحث ونسخة مقروءة لصفحة الإدارة)، وحالة الحساب وتاريخ إنشائه ومدة الاشتراك. ولكل اشتراك: رقم الحزمة والمادة والفصل وتاريخ الانتهاء وحالة الإلغاء. وعدّاد يومي لعدد التنزيلات لكل حساب (الحد 20 يوميًا) دون تسجيل أسماء الحزم.
  • ما لا يحفظه الخادم: البريد الإلكتروني، معرّف الجهاز، عنوان IP، متصفحك، بيانات الدفع، محتوى الدروس، سجل التفعيل. لا يحتفظ تطبيقنا بسجلات للطلبات. يعمل الخادم على Cloudflare Workers، وتخضع بيانات الشبكة التي تعالجها Cloudflare لسياستها هي.
  • ما لا نجمعه أصلًا: لا بيانات بطاقات أو دفع (الدفع خارج الإضافة)، ولا بيانات دخولك إلى نور، ولا محتوى صفحات نور، ولا أسماء الطلاب أو درجاتهم، ولا مفاتيح الذكاء الاصطناعي.
  • الحذف: لا حذف تلقائي. تُحذف بيانات اشتراكك عند الطلب من المسؤول. ملفات الحزم تُحفظ في مستودع خاص.

English

Summary: we do not sell data, show ads or track you. The only server we operate is a license server used to verify your activation code and download library packs. We never see Noor data, student names or grades. Barq is an independent tool and is not affiliated with the Ministry of Education.

License server (activation code)

  • Server: https://barq-license.barq-noor.workers.dev
  • Sent: on activation, only the activation code you type. After that, a session token issued by the server (valid for 3 days) when refreshing your subscription and when downloading a lesson pack.
  • Returned: the list of packs your subscription allows and the lesson files (JSON data only, no executable code).
  • Stored on your device: the session token, the allowed pack list and downloaded packs, in extension local storage.
  • Stored by the server, per subscriber: the name or label typed by the administrator, an optional WhatsApp number (used only to send you the code), the activation code (a hash for lookup and a readable copy for the admin page), account status, creation date and chosen period. Per subscription: pack id, subject, semester, expiry and a revoked flag. A daily download counter per account (limit 20 per day), without pack names.
  • Not stored by the server: email, device id, IP address, user agent, payment data, lesson content, activation history. Our application keeps no request logs. The server runs on Cloudflare Workers; network-level data handled by Cloudflare falls under Cloudflare's own policy.
  • Not collected at all: card or payment data (payment happens outside the extension), Noor login details, Noor page content, student names or grades, AI keys.
  • Deletion: no automatic deletion. Your subscription data is deleted on request by the administrator. Pack files are kept in a private repository.

Other data

  • AI provider keys stay in local storage and go only to the provider you chose, over HTTPS.
  • Lesson content is sent to your chosen AI provider only when you use generation or search, with your own key. Noor pages, student names and grades are never sent.
  • Grade entry reads names and grades inside your browser only; nothing is sent or saved. The extension never presses Save in Noor.
  • Your registration email stays on your device.
  • Optional ntfy.sh notifications only if you enter a topic name.
  • Removing the extension deletes all local data.
