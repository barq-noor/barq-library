# مكتبة برق (خاص)

تحضيرات جاهزة لإضافة «برق»، مراجَعة استقلالًا قبل الرفع. المستودع خاص ولا يُنشر دون قرار المالك.

- `index.json`: الفهرس (مادة، صف، فصل، عدد الدروس، رقم النسخة v، البصمة sha256).
- `packs/`: حزمة لكل مادة وصف وفصل. الصور فيها مفصولة (`"images":"separate"`).
- `img/`: صور مقصوصة من الكتاب بصيغة webp، تُجلب عند اختيار الحزمة فقط.
- `build_index.py`: يعيد توليد الفهرس بعد أي تعديل (`python3 build_index.py`).

على المعلم مراجعة كل تحضير وتعديله بما يناسب صفه قبل الاستخدام.
