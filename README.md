# Barq

مكتبة برق: تحضيرات جاهزة لإضافة «برق»، مخصصة لاستخدام المعلمين. المنشور هنا حاليًا المواد التي اكتملت ومرّت بالمراجعة: العلوم (الأحياء والكيمياء والفيزياء)، واللغة العربية، والتربية الإسلامية، والرياضيات، والدراسات الاجتماعية. تُضاف بقية المواد عند اكتمالها. النسخة بلا صور من كتب الوزارة: يُستبدل كل شكل بملاحظة «انظر الشكل في كتاب الطالب».

- `index.json`: الفهرس (مادة، صف، فصل، عدد الدروس، البصمة sha256).
- `packs/`: حزمة لكل مادة وصف وفصل.
- `privacy/`: صفحة الخصوصية.

على المعلم مراجعة كل تحضير وتعديله بما يناسب صفه قبل الاستخدام.
