# مكتبة برق

تحضيرات جاهزة لإضافة «برق»، مراجَعة استقلالًا قبل الرفع، ومخصصة لاستخدام المعلمين.

تنبيه: الكتب المدرسية الأصلية وما فيها من صور ورسوم ملك لوزارة التربية والتعليم في سلطنة عُمان. الصور في هذه المكتبة مقصوصات من تلك الكتب لغرض التعليم فقط.
على المعلم مراجعة كل تحضير وتعديله بما يناسب صفه قبل الاستخدام.

## المحتوى
- `index.json`: الفهرس (مادة، صف، فصل، عدد الدروس، رقم النسخة v، البصمة sha256).
- `packs/`: حزمة لكل مادة وصف وفصل. الصور فيها مفصولة (`"images":"separate"`).
- `img/<المعرّف>.txt`: صورة مقصوصة بصيغة data URL (webp)، تُجلب عند اختيار الحزمة فقط.
- `build_index.py`: يعيد توليد الفهرس بعد أي تعديل (`python3 build_index.py`).
